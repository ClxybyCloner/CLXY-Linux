## Upstream Project & Original Linux Core
CLXY — CLONER X-RAY for Linux integrates the original Linux Core implementation from:
- **Project:** Arman VPN Client (Linux Core)
- **Reference Repository:** [https://github.com/armanlife/arman-vpn-client](https://github.com/armanlife/arman-vpn-client)
